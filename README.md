# محرك بيانات المطارات السورية (Syrian Airport Data Engine)

منظومة تحليلية متكاملة (Full-Stack) لمعالجة بيانات عمليات الطيران، ومطابقة الجداول الزمنية، والتحليل التاريخي لحركة النقل الجوي في الجمهورية العربية السورية، مع تركيز معمق على **مطار دمشق الدولي (`DAM / OSDI`)** إلى جانب المطارات المدنية السورية (**حلب `ALP`، اللاذقية `LTK`، دير الزور `DEZ`، القامشلي `KAC`، وتدمر `PMS`**).

المنطقة الزمنية المرجعية المعتمدة للمشروع: `Asia/Damascus` مع توحيد الطوابع الزمنية إلى `UTC` والفصل الصارم بين مستويات الإثبات المصدري.

---

## 1. نبذة عن المشروع والمبادئ المنهجية

يهدف المشروع إلى توفير مرجع بيانات تجريبي قابل للتدقيق والمراجعة لحركة الطيران المدني في سوريا، بعيداً عن التقديرات العشوائية أو توليد الأصفار الافتراضية مكان فجوات التغطية.

- **فصل طبقات الإثبات (`flight_events`)**: يعزل المحرك `1,830` سجلاً معيارياً إلى أربع فئات مستقلة:
  - `physical_movement` (**`131` سجلاً**): حركات مبلّغ عنها تشغيلياً وتجارياً وفق قواعد المشروع (لا تُعامل كإثبات راداري أرضي مباشر للمدرج).
  - `scheduled_service` (**`1,662` سجلاً**): رحلات مجدولة عبر شاشات العرض والمنصات دون تأكيد تتبع مستقل.
  - `marketing_codeshare` (**`34` سجلاً**): إدراجات مشاركة الرمز التسويقية.
  - `unverified_movement` (**`3` سجلات**): حركات لوحة غير موثقة بمصادر كافية.
- **دفتر الأدلة غير القابل للتعديل (`event_evidence`)**: يضم `1,508` سجل إثبات خام مرتبطاً بالأحداث، مع تطبيق تصحيح دلالي تلقائي عند القراءة لـ `76` سجلاً مشتقاً من حقول تقديرية (`35` إقلاعاً و`41` هبوطاً) بنسبة `5.04%` عبر **تقرير التدقيق السريع** دون تعديل الصفوف الأصلية.
- **أرشيف شاشات دمشق المؤرشفة (`archived_fids_analytics.db`)**: يحفظ `6,923` خانة عرض مؤرشفة من بوابة مطار دمشق (`2026-07-05` إلى `2026-09-09`) مفصولة كلياً عن سجلات أكتوبر التشغيلية.
- **السلاسل الإقليمية المجمعة لعام 2024 (`DAM_ALP_LTK`)**: `438` صفاً تغطي مطارات دمشق وحلب واللاذقية مجتمعة، ويُحظر منهجياً نسبتها إلى دمشق وحدها.
- **سياسة شفافية الفجوات**: لا يُحوَّل غياب القياس إلى صفر؛ بل تبقى الأيام المفقودة مصنفة كفجوات بيانات تاريخية (`unverified_data_gap`).

## 2. الواجهات والقدرات التفاعلية (دعم كامل للعربية RTL)

تم بناء واجهة المستخدم بالكامل باللغة العربية واتجاه `RTL` مع تخطيطات ورسوم بيانية متكيفة:

1. **المستكشف الشبكي المكاني (`NetworkGraphCanvas`)**: رسم شجري تفاعلي يربط المطارات السورية، وطبقات الإثبات، وناقلات أرشيف FIDS، والممرات الجوية، وملخصات التدقيق، مع بحث ثنائي اللغة (عربي/إنجليزي/IATA).
2. **خريطة المسارات والكثافة الجغرافية (`CorridorMapCanvas` — D3.js)**:
   - إسقاط جغرافي `Natural Earth` عالي التباين بدقة `50m` للدول المتصلة وكثافتها (`17` دولة متصلة، `45` ممراً).
   - **تظليل المجال الجوي (`d3.geoCircle`)**: عند النقر على أي مطار سوري أو مسار وجهة، يظهر نطاق التحكم الجوي الداخلي والخارجي مع تقاطعات رادارية.
   - **أسهم اتجاه الحركة المتحركة**: أسهم انسيابية على طول المنحنيات تميّز رحلات المغادرة (ذهبي) عن رحلات الوصول (زمردي) مع زر تحكم واحترام إعداد `prefers-reduced-motion`.
3. **مصفوفة التغطية الزمنية (`CoverageMatrixHeatmap`)**: مصفوفة تفاعلية من `5,175` خلية (`5` محطات × أيام الفترة `2024-01-01 → 2026-10-31`) مع تلميحات تفصل السجلات الموثقة والتجارية وخانات FIDS لكل يوم.
4. **تدقيق التغطية وتقرير التدقيق السريع (`CoverageAuditView`)**: لوحة **تقرير التدقيق السريع** بمخطط دائري تفاعلي يعرض نسبة السجلات المعاد تصنيفها تلقائياً مقابل الأصلية، بالإضافة إلى جداول التغطية لـ `34` شهراً، وصحة مصادر التدفق، ولقطات أرشيف واي باك (`CDX`)، وبيانات `2024 DAM_ALP_LTK`.
5. **سجل أحداث الرحلات والفحص الجنائي (`FlightOpsView`)**: استعلام وتصفية متعددة المحاور (بما في ذلك الوجهات المتعددة والبحث العربي) مع درج فحص جنائي للحقول الزمنية الستة المنفصلة ودفتر الإثباتات.
6. **مراقب الحركة الجوية وأرشيف FIDS ونظرة العمليات والتصدير**: لوحات قياس بمؤشرات اتجاه شهرية، رسوم مقارنة يومية وساعية، وتصدير فوري بصيغ `CSV` و`JSON` و`Excel (.xlsx)` مع ملفات التعريف الجانبية (`Sidecar Metadata`).

## 3. المكدس التقني

- **الواجهة الأمامية**: React 19، TypeScript، Vite 8، Tailwind CSS v4، D3.js 7، TopoJSON (`world-atlas`)، Lucide React.
- **الخادم والبيانات**: Node.js (v22+) مع `node:sqlite` المدمج (قراءة فقط لقواعد SQLite المحلية)، Express 4، `tsx`، `xlsx`، `csv-parse`.

---

## 4. التثبيت والتشغيل

### المتطلبات الأساسية
- **Node.js 22.0 أو أحدث** (مطلوب لدعم وحدة `node:sqlite` المدمجة).
- **npm** لإدارة الحزم.

### خطوات التشغيل المحلي

1. تثبيت الاعتماديات:
   ```bash
   npm install
   ```

2. متغيرات البيئة (اختياري):
   انظر `.env.example` في جذر المشروع (`PORT=3000`).

3. تشغيل خادم التطوير (Express + Vite على المنفذ `3000`):
   ```bash
   npm run dev
   ```
   ثم افتح المتصفح على: `http://localhost:3000`

4. التحقق من الأنواع والبناء الإنتاجي:
   ```bash
   npm run lint
   npm run build
   npm start
   ```

## 6. أبرز واجهات البرمجة (REST API)

| المسار | الطريقة | الوصف |
| :--- | :--- | :--- |
| `/api/airports`, `/api/airport` | `GET` | بيانات المطارات السبعة المسجلة ومواصفاتها والمدارج |
| `/api/flights` | `GET` | سجل أحداث الرحلات مع التصفية (بما فيها الوجهات المتعددة والبحث) |
| `/api/events/:event_id`, `/api/events/:event_id/evidence` | `GET` | تفاصيل الحدث ودفتر الإثباتات غير القابل للتعديل والتصحيح الدلالي |
| `/api/corridors` | `GET` | المسارات الجوية وإجماليات الدول (ISO) لخريطة D3 |
| `/api/coverage/heatmap`, `/api/historical-coverage/timeline` | `GET` | مصفوفة التغطية اليومية والشهرية (5,175 خلية) وسجل 34 شهراً |
| `/api/evidence/audit` | `GET` | إحصائيات تدقيق الإثباتات (المعاد تصنيفها تلقائياً مقابل الأصلية) |
| `/api/air-traffic/kpis`, `/api/air-traffic/monthly-summary` | `GET` | مؤشرات الأداء الشهرية والاتجاهات المقارنة |
| `/api/archived-fids/*` | `GET` | ملخصات وناقلو وخطوط أرشيف شاشات دمشق (FIDS) |
| `/api/ingestion/health`, `/api/historical-archive/captures` | `GET` | صحة مصادر البيانات وحالة لقطات واي باك |
| `/api/export/:dataset`, `/api/export/:dataset/sidecar` | `GET` | تصدير البيانات بصيغ CSV / JSON / XLSX مع الملف الوصفي الجانبي |

## 7. حدود البيانات والضمانات المنهجية

1. **غياب القياس لا يساوي الصفر**: الأيام أو المحطات الخالية من السجلات تمثل فجوة في الاسترجاع المصدري لا توقفاً للرحلات.
2. **حماية السجلات التاريخية**: كافة اتصالات قواعد البيانات مفتوحة بوضع القراءة فقط (`readOnly: true`) مع تطبيق التصحيحات الدلالية عند القراءة وإظهار أصل كل معلومة بشفافية.
3. **عدم الخلط بين النطاقات**: تبقى أرقام `2024 DAM_ALP_LTK` الإقليمية وأرصاد أكتوبر التجارية وأرشيف `Wayback FIDS` مفصولة بوضوح في الواجهة وواجهات البرمجة.
